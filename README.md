# E-Commerce Sales Data Analysis — SQL

This project analyzes an e-commerce database using SQL to generate insights on sales, customers, and product performance — simulating real-world business analysis tasks.

## Database Structure
5 tables: Customers, Products, Orders, Order_Items, Payments

## SQL Concepts Used
- Joins, Subqueries, Aggregate Functions (SUM, COUNT, AVG)
- Stored Procedures, Triggers, SQL Functions

## Business Analysis Performed
- Total revenue analysis
- Top customers by spending
- Best-selling products
- Payment method trends
- Order distribution per customer

## Tools Used
SQL, MySQL
